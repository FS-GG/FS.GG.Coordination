# GS2-05.2 organization issue-field evidence

This directory is the immutable, repository-local Q2 evidence subject for the registered
organization issue-field contract. `corpus.json` freezes every current Coordination Project field,
type, and option plus canonical representative migration rows. `independent-expectations.json` is a
separately authored oracle for vocabulary, refusal, and preservation coverage.

`organizationIssueFields.quint` is the plain single-actor model; the sibling test module exercises
accepted and refused paths. `qualification.json` binds the exact registered unit, command, and
artifact bytes. The gate performs no network request or GitHub mutation.
