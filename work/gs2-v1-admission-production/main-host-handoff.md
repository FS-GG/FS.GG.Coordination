Custody or source review alone never authorized that write, and this interface is not a standing permit for another signer, JWT, or installer invocation.

This is an execution interface, not an approval or an instruction to create the journal by itself. Run it only after both reviewed PRs are merged, the dedicated workflow has succeeded with native owner approval, and the fresh `prepare` output agrees with the workflow inputs. The operator must keep the private keys in Main's KDE Secret Service. Never paste a PEM, JWT, installation token, or secret-tool output into chat, a shell argument, a file, or a log.

The Main-only helper is `eng/github-v1-admission-main-custody.py`. It needs `eng/github-v1-admission-protected-read.py` beside it, `secret-tool`, `openssl`, and an authenticated `gh` client able to read the private `.github` run and artifact. It must not be run inside fsharp-dev-2. The ordinary wallet lookup is `service=fsgg-ledger-protection, role=ordinary, app-id=4882140`. The current-authorizer lookup is distinct and exact: `service=fsgg-v1-admission, role=authorizer, key-id=main-gs2-08-2-authorizer-2dc8d29f8d5a675d, spki-sha256=2dc8d29f8d5a675d070701dacd6dacf2ca3e368ecf823fa9eaf560ddd22d77be, trust-anchor-sha256=0a9f84f72ca10c01b5acc386a32ce6920fea15231f90f65a8f17df9e87d9a779`. The older `fsgg-ledger-protection/authorizer` record must not sign for this anchor. The helper keeps private bytes in process memory and an anonymous descriptor; it never exports a PEM.

The container runner is `eng/run-v1-admission-genesis.fsx`. It needs a Release build, a public trust-anchor JSON whose digest matches the verified genesis plan, and an authenticated read-only `gh` session. Its `--source-commit` is the merged Coordination revision. `prepare` emits `sourceCommit`, `sourceTree`, `workflowRevision`, `genesisIntentSha256`, and `operationId`; pass the first two as the workflow's `coordination_revision` and `coordination_tree`, and the intent and operation values as its matching inputs. Dispatch the pinned workflow revision on `.github/main` as the accountable owner. A successful run is not enough until the native approval, environment and artifact are reread by both the Main helper and installer.

After the run succeeds, the container `signing-payload` mode writes a public canonical JSON payload using the pinned `--workflow-revision` and `--run-id`. Transfer only this public payload and the public trust anchor to Main. On Main, invoke `python3 eng/github-v1-admission-main-custody.py sign-intent --payload PAYLOAD.json --trust-anchor trust-anchor.json --output envelope.json`. This command independently rereads the run, verifies its receipt and the trust-anchor public fingerprint, and writes only a public-key/signature envelope. Transfer only that envelope back to the container. The helper refuses to overwrite an existing output.

For `apply`, Main must connect `python3 eng/github-v1-admission-main-custody.py issue-jwt --run-id RUN_ID` stdout directly to an inherited pipe that becomes FD 3 of the container runner. The CLI refuses a terminal or regular-file stdout before reading native approval or a key. Do not capture or print the JWT. The runner's remaining arguments are `apply --source-commit SHA --trust-anchor trust-anchor.json --workflow-revision SHA --signature-envelope envelope.json --app-jwt-fd 3`. The JWT is short-lived and issued only after another native approval read. The runner obtains a one-repository, contents-write installation token, binds the four exact Git objects, performs all fresh typed checks, and attempts one expected-absent ref creation. An indeterminate result is not permission to retry blindly: independently read back the canonical operation ref and exact objects first. The runner prints `GENESIS_INSTALLED` or `GENESIS_ALREADY_INSTALLED` only after exact readback; retain that receipt and verify the ref again from a separate read-only client.

No workflow dispatch, signer invocation, JWT issuance, or journal mutation follows from the earlier custody fingerprint check alone. If the host cannot perform the narrow pipe and public-file transfer, stop before `apply` and report that host access is missing.
