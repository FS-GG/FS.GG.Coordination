# Source-only exact-parent CAS fixture

`eng/github-v1-admission-journal-cas.py` validates the complete public append plan (fixed repository and admission ref, parent and proposed commit, two exact blobs, canonical two-entry tree, and deterministic one-parent commit) before any write boundary. Its fixture path requires an absolute local bare-Git directory. It fetches the current parent, stages only verified object bytes, and pushes under `--force-with-lease=<canonical-ref>:<expected-parent>`. A preflight parent move is a conflict; a failed or lost push response remains unknown until independent journal readback. Four local bare-Git tests cover a successful append, stale parent, a concurrent sibling update, lost success, and tampering. Q6 runs these tests.

This is deliberately **not** a production writer or a deployment entry point. It has no ordinary-App credential channel and refuses a network remote. The production slice must add a scoped, secret-safe Git receive-pack transport, wire it to the typed `RegistryJournalPort`, and independently reread the exact installed journal after every outcome. The ordinary CLI production fence stays in place. The wrong public trust anchor still blocks protected genesis installation; this fixture does not relax that gate.
