# Closed protected operation-plan read adapter

Status: source and fake-store controls, 2026-09-25, stacked on [#592](https://github.com/FS-GG/FS.GG.Coordination/pull/592). The [adapter](../../eng/callable_isolated_v2_operation_plan_read_adapter.py) implements the final operation-plan port of the [five-observer candidate contract](candidate-observer-port.md). It does not create a store, protected seal, token, journal, grant, provider transport or dispatch command. The #563 inspect-only workflow remains disabled.

The plan read port accepts one numeric record ID and returns at most 16 KiB of canonical JSON. The record binds the candidate digest, immutable source tree, workflow revision, selected run and attempt, independent review event, complete selected target, one POST operation, and canonical request object. The adapter derives the current native v2 PR title, head, base and deterministic effect marker from the exact selected refs/SHAs, then hashes the canonical request bytes and compares them with the operation request SHA-256. It refuses malformed refs or SHAs, changed target, actor/run/review, extra or duplicate fields, alternate method/path, more than one provider write and noncanonical bytes.

The plan store's read-only scope is checked before and after the raw read. A distinct injected protected seal reader must attest the exact plan-body SHA-256, record ID, candidate/source/workflow/run/review/target/operation IDs, seal time and expiry. The reader and sealer must have identities and credentials distinct from each other and from the four other observer envelopes. These interfaces are not authenticated implementations; matching fake objects establish consistency only. A protected owner must define the immutable backend, actual principals, credential custody, seal issuance/revocation and readback before this adapter can qualify evidence. There is no one-use execution grant in this plan.

The [fake controls](../../eng/tests/callable-isolated-v2-operation-plan-read/test_operation_plan_read_adapter.py) cover wrong run/attempt/actor/review, target/ref/request, malformed source SHA, broad reader scope, duplicate and noncanonical JSON, absent/replayed/stale seal, scope drift and sanitized exceptions. A matching control closes file, token environment, socket and SQLite access. The malformed SHA control was red before validation was added. Tests exercise no protected store or provider.

The five local observer ports now have source-level shapes, but the source/release port has no protected implementation and all observer identities remain caller-supplied. Protected App transport/permission attestation, independent approval event ID/time, complete target prestate, execution credential issue record, exact effect artifact/workflow, durable CAS and one-use grant remain missing. No native POST, receipt, gate/index change, Authority write or cutover is authorized by this draft or by a matching synthetic candidate.
