# Closed effect scaffold Git-tree source witness

Status: source-only, non-authorizing. The [closed effect release preflight](effect-release-preflight.md) verifies archive and manifest bytes but its injected source claim alone does not prove that the source files belong to the selected Coordination commit. This witness closes that source-consistency gap for a future protected read-only implementation; it does not select or approve a commit.

`eng/callable_isolated_v2_effect_git_tree_witness.py` accepts a closed preflight result, its exact archive/workflow/manifest/builder/native input bytes, a selected repository ID and separate source-reader custody claim, and an injected Git object reader. It reruns the exact scaffold byte verifier, extracts the three archive member source files, and requires all seven source paths to match the selected Git commit and tree. The reader returns raw commit, tree and blob objects. The witness recomputes each Git SHA-1 object ID, checks the commit's tree line, walks exact tree entries, requires regular `100644` source files, and compares complete blob bytes. Reader scope must be exact read-only Coordination repository scope, unexpired and unchanged before/after, with a principal and credential distinct from the selected source reader. Output remains `authorized=false`, `can_dispatch=false`, `live_effects=0`.

Fake controls first failed because the module did not exist. They now cover wrong commit/tree, changed builder bytes, independently changed Git blob bytes, a coherent Git tree containing a symlink-mode workflow path, shared reader credential, scope drift and missing objects. The matching fake denies file, environment-token, socket and SQLite access during qualification.

The contract assumes a SHA-1 Git object repository; a protected reader must establish the repository's actual object format and authenticate every returned object and its selected repository ID outside these fake port claims. The witness cannot prove that the preflight result came from a protected producer, that the selected source reader is real, that a producer run used this tree, or that an artifact was downloaded from that run. The [protected owner packet](effect-release-owner-evidence.md) still requires independent producer, approval, runner and audit custody. Both workflows remain disabled; #545's disputed receipt and the [#550 native one-attempt gate](https://github.com/FS-GG/FS.GG.Coordination/pull/550) remain held. No protected install, credential, grant, journal/CAS, provider POST, Authority write or cutover follows from this result.
