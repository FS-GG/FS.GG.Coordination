# Closed v5 registry-key signature byte join

Status: source-only fake-port candidate stacked on draft #801. The [registry witness](../../eng/callable_isolated_v2_v5_key_registry.py) now carries the exact 32 public-key bytes, repository ID, reader identity and observation/expiry times. The [post-registry adapter](../../eng/callable_isolated_v2_v5_keyed_signature.py) independently parses the canonical envelope, binds its hash, nonce, issuer event and key ID to the preceding witnesses, then passes **those registry-selected public-key bytes** with the exact canonical payload and signature to an injected verifier. It accepts only literal `True`, a narrow distinct verifier reader and an unexpired registry observation. Its result fixes `authorized=false`, `can_dispatch=false` and `live_effects=0`.

The [tests](../../eng/tests/callable-isolated-v2-v5-keyed-signature/test_v5_keyed_signature.py) began red because the adapter was absent. They reject a swapped public key, digest, key ID, envelope or nonce, duplicate JSON fields, malformed signature bytes, false or integer verifier results, reused reader identity, broad scope, expired registry data and any local file, token-environment, socket or SQLite access. The [registry tests](../../eng/tests/callable-isolated-v2-v5-key-registry/test_v5_key_registry.py) check that the selected bytes reach its closed result.

This is a byte-binding interface, **not** cryptographic verification or protected key approval. The injected verifier may return `True` without checking a signature; the registry and its prior approval/after-signing observation are fake records. A protected owner must independently authenticate immutable key approval and revocation, select an actual verifier implementation that consumes the approved public key, prove the exact envelope/nonce/run binding and installed no-grant refusal, and approve integrated source/artifact/runner identities. Both workflows stay disabled; #550 native one-POST, #545 disputed receipt, protected merge, Authority write and cutover remain held.
