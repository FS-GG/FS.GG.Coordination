# Closed source and release read adapter

Status: source and fake transport only, 2026-09-25, stacked on [#594](https://github.com/FS-GG/FS.GG.Coordination/pull/594). The [adapter](../../eng/callable_isolated_v2_source_release_read_adapter.py) implements the remaining source/release port of the [five-observer candidate contract](candidate-observer-port.md). It has no HTTP client, token lookup, artifact downloader, installer, grant, journal or dispatch entry. The #563 inspect-only workflow remains disabled.

GitHub documents [Git commit objects](https://docs.github.com/en/rest/git/commits#get-a-commit-object), [specific workflow run attempts](https://docs.github.com/en/rest/actions/workflow-runs#get-a-workflow-run-attempt) and [artifact metadata](https://docs.github.com/en/rest/actions/artifacts#get-an-artifact). The injected reader requests only the selected immutable Coordination commit, producer run attempt and artifact ID. It requires exact commit/tree SHA and URLs, selected repository and head repository, completed successful workflow dispatch from main with one producer actor, and artifact ID/name/download URL/run/head/repository identity. It rejects redirects, non-200 responses, duplicate JSON and a changed read-only Actions/Contents/Metadata scope claim. That claim does not authenticate the App or effective permissions.

The separate injected bundle reader returns raw ZIP bytes for the selected artifact. The adapter requires GitHub's published SHA-256 digest and exact size to match those bytes, and accepts only three regular, bounded members at fixed operator, control and proposed effect archive paths. It hashes each member and refuses the known #555 inspect-only archive digest. A third, distinct protected attestor must bind the three JSON response hashes, bundle digest, member digests, source tree, producer run/attempt/actor/artifact, release workflow path and immutable runtime/image/interpreter closure facts. No such attestor or effect artifact exists here. GitHub's documented artifact object names a run but does not show an attempt ID; future attestation must independently establish the artifact's attempt provenance. [Artifact download](https://docs.github.com/en/rest/actions/artifacts#download-an-artifact) returns a short-lived redirect, so its protected implementation also needs independently reviewed redirect, host, byte and token custody. This adapter does not follow that redirect.

The [fake negative controls](../../eng/tests/callable-isolated-v2-source-release-read/test_source_release_read_adapter.py) invert commit/tree, run attempt/status/actor/repository, artifact ID/head/URL, bundle members/size/digest, scope and attestation, plus redirect, duplicate JSON, drift and sanitized exceptions. Matching fake execution patches file, token environment, socket and SQLite access closed. Failed producer status and missing published artifact digest were red-before controls. These are local refusal tests; they are not an installed or protected release.

All five observer ports now have source-only adapters or interface shapes, but no authenticated protected implementation. The actual effect archive and workflow, distinct producer/observer identities, immutable review-event ID/time, selected target prestate, execution credential issue record, durable CAS, one-use grant, installed no-grant refusal and native one-POST readback remain held. No matching synthetic packet clears the typed ceiling, gate/index, #545 receipt, Authority boundary or cutover.
