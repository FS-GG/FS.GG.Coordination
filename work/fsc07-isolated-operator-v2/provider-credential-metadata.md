Status: token-free fake metadata proposal, stacked on [#752](https://github.com/FS-GG/FS.GG.Coordination/pull/752). The [join](../../eng/callable_isolated_v2_provider_credential_metadata.py) compares the closed [provider request specification](provider-request-spec.md) and typed native coordinates with the existing effective App-scope witness shape. It has no token reader, GitHub client, grant, journal writer or dispatch path and is outside the installed archive.

The source requires one selected repository and installation, exact `metadata:read`, `contents:read`, `pull_requests:write` effective permissions, selected public credential ID and mint digest, distinct metadata-reader credential, target/prestate digest, fresh observation and expiry covering the proposed grant window. It also rechecks the request URL, native POST method/path/body bytes and one-write ceiling. Red-before controls found that a foreign native path, then changed method, write ceiling, body and operation identity could pass a scope-only comparison; those coordinates now refuse. The output is always `authorized=false`, `can_dispatch=false`, `live_effects=0` and contains no token bytes.

The [tests](../../eng/tests/callable-isolated-v2-provider-credential-metadata/test_provider_credential_metadata.py) first failed because the module was absent. They now cover a foreign App, repository, installation, permission, credential, mint, target, prestate, reader, time, native request and malformed metadata. A matching fake witness cannot prove token bytes correspond to its public credential ID, that the App grant is effective at send time, or that its reader is protected and independent. Those require an owner-selected protected App installation, authenticated mint/effective-scope observations, token custody and a separately reviewed installed adapter. Neither this result nor [#550](https://github.com/FS-GG/FS.GG.Coordination/pull/550) authorizes a POST. The closed archive and disabled workflows remain unchanged; [#545](https://github.com/FS-GG/FS.GG.Coordination/pull/545) receipt, protected merge, Authority write and cutover stay held.
