# Closed v5 issuer signature envelope boundary

Status: source-only candidate stacked on draft #790. The [issuer result](../../eng/callable_isolated_v2_v5_runner_issuer.py) now carries event time and its fake reader identity. The [envelope adapter](../../eng/callable_isolated_v2_v5_issuer_envelope.py) requires canonical versioned JSON, no duplicate fields, a 64-byte base64 signature, a selected key fingerprint and nonce, and exact claims for the chosen source tree, artifact, install approval, runner run/attempt, actor, image/runtime and path. It sends the exact canonical payload bytes and signature to one injected verifier port. Only the literal boolean `true` is accepted. Its outcome remains `authorized=false`, `can_dispatch=false`, `live_effects=0`.

The [tests](../../eng/tests/callable-isolated-v2-v5-issuer-envelope/test_v5_issuer_envelope.py) began red because the adapter was absent; a separate red test showed the issuer result lacked event time and reader identity. Independent negatives reject swapped run, actor, image, approval event, key or nonce, duplicate/noncanonical JSON, invalid signature bytes, verifier return `1`, reused verifier reader, broad scope and any file, token-environment, socket or SQLite access during qualification.

The verifier is a **fake port**. A fake `true` does not authenticate a signature, issuer or protected key. Before using this contract, a protected owner must independently approve an immutable public key and algorithm, supply an actual verifying implementation and audit event, and bind a replay-resistant nonce to the selected run. That decision also requires the integrated source/workflow, producer artifact, runner image/runtime and installed no-grant refusal. This draft does not select a key, issue a grant, enable either workflow or perform any effect. #550 native one-POST, #545 disputed receipt, protected merge, Authority write and cutover remain held.
