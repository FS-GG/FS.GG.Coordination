# Closed review and membership read adapter

Status: source and fake transport only, 2026-09-25, stacked on [#589](https://github.com/FS-GG/FS.GG.Coordination/pull/589). The [adapter](../../eng/callable_isolated_v2_review_read_adapter.py) implements the review observer port of the [candidate contract](candidate-observer-port.md). It creates no HTTP client, reads no token, opens no journal, issues no grant and has no dispatch entry. The #563 inspect-only workflow remains disabled.

GitHub documents [review history for a workflow run](https://docs.github.com/en/rest/actions/workflow-runs#get-the-review-history-for-a-workflow-run) at `GET /repos/{owner}/{repo}/actions/runs/{run_id}/approvals` with repository Actions read permission. Its published response identifies the reviewing user and environment, but does not show an immutable approval event ID or approval timestamp. GitHub also documents [organization membership for a user](https://docs.github.com/en/rest/orgs/members#get-organization-membership-for-a-user) at `GET /orgs/{org}/memberships/{username}` with organization Members read permission. The adapter therefore requires three injected and mutually distinct observations: the selected workflow/run observation from #589, a read-only Actions/Members transport, and an independently authenticated protected review-event reader. That last reader has no implementation here. A caller-supplied audit dictionary cannot establish real event provenance by itself.

The selected workflow observation binds candidate digest, run ID, attempt and dispatch actor. A red-before control showed that one reused mutable review-reader scope dictionary could change its credential at the final read without detection; the adapter now snapshots each validated scope. The transport claims the exact `FS-GG/.github` repository ID and `FS-GG` organization with only `actions:read`, `members:read`, `metadata:read`; the adapter checks that claim before and after reads. Its only requested paths are `repos/FS-GG/.github/actions/runs/{runId}/approvals` and `orgs/FS-GG/memberships/{reviewerLogin}`. It refuses redirects, pagination headers, non-200 responses, duplicate JSON keys, a missing or multiple approvals, wrong reviewer or environment IDs/names/API URLs, an inactive or foreign organization membership, and scope drift. It hashes the exact approval response bytes and passes that hash to the separate audit port. The audit result must bind the same run, attempt, environment, reviewer and response hash, with a distinct principal and credential, positive event ID, and a UTC approval time within 30 minutes of observation and expiry. The output is only a review observation envelope for #587.

The [independent fake controls](../../eng/tests/callable-isolated-v2-review-read/test_review_read_adapter.py) cover foreign actors, environment, membership, run, attempt, audit event, stale approval, broad or drifting claimed scope, redirect and exception sanitization. The matching control patches file, token environment, socket and SQLite access closed. These controls prove local refusal logic only; no protected approval, membership or audit event was fetched.

Before this can qualify a protected candidate, an owner must select a real run and reviewer, install a separately reviewed read-only GitHub App transport with fixed `https://api.github.com` host, attest installation identity and effective repository/organization permissions independently of its self-reported `scope()`, and supply an independent immutable approval-event source that names event ID, UTC time, run attempt, reviewer and environment. Its provenance and custody must be distinct from the workflow reader, dispatch actor and eventual selected-target execution token. The selected target/App-scope and operation-plan observers also remain unimplemented. Even a complete read-only observation would not authorize the native one-POST effect; #550 target, execution credential, durable CAS, one-use grant and full native readback still require their own protected decision. Gate/index, #545 receipt and cutover remain held.
