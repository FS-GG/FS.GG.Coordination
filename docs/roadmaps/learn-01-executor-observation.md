## Decisions and boundaries

1. Keep Observer inert. Reuse its existing typed journal and `IBoundedPlanningCapability` reservation/reconciliation path. Put effectful joining in the existing Host composition; no second executor, service or model router. A compiler result is data, not authority. Its shadow flags remain unchanged.
2. Add an explicit versioned planning disposition (`reuse-valid-plan`, `planned`, `direct-small`) at the authoritative adapter boundary. A real validated keep requires no planner; planned work requires Astra high; direct-small still requires every existing eligibility fact. Preserve old event/digest decoding and original assignments; do not rehash history or silently relabel legacy records.
3. A trusted preparation adapter resolves original/member identities against complete O1 canonical WorkItem observations and the declared root lineage. It validates the exact accepted proposal, contract revision, obligation set and independently retrieved source bytes. Hashes supplied by a caller are not content verification or approval. Existing command/approval authority remains required where consumed.
4. Persist the original treatment first. Then bind each execution's canonical WorkItem, original treatment digest, item/parent relation, existing assignment/attempt/generation, accepted proposal, child-specific context/input digest, finite bounds and requested profile in the existing durable admission path. The binding references original hashes; it never changes them. A lost response reuses the same binding. A changed manifest requires a separately authorized invocation under the same treatment and original budget accounting.
5. Capability assessment is `supported`, `unsupported` or `unknown`, bound to provider/adapter/executable and exact requested model/effort. Only supported may enter a learning-qualified launch. Static schema, login success, a configured allowlist and echoed request alone are not native support evidence. A real discovery adapter must be tied to an actually supported pinned provider surface; if unavailable, the production result is explicitly unknown and the qualified live effect refuses. Source fixtures can still prove positive and negative wiring. Do not add a new provider transport solely to fabricate a positive result.
6. Requested/locally selected/native observed identity are distinct. Observed mismatch is retained as a deviation on the original assigned arm, including incurred cost, with no redraw or automatic model fallback. Missing observation stays unknown. Unknown terminal execution retains the existing reconciliation fence; telemetry loss does not manufacture success or block unrelated ordinary delivery.
