# GitHub fleet dry plans

GS2-06.8 closes the GS2-06 milestone with a pure qualification boundary. A
complete read-only census is converted into a deterministic plan; the contract
cannot send requests or apply operations. Its length-framed SHA-256 seal binds
the accepted roadmap and prerequisite receipts, exact roster and source
revision, repository identities and default branches, observations, desired
state, dispositions, permissions, ordered operations, and repair intent.

Compilation fails closed on missing repositories or settings, malformed
pagination, invalid status/disposition combinations, or invalid authority.
Unsupported and indeterminate capabilities remain visible and suppress writes;
the externally owned repository is always observation-only. A supported
setting produces a `would-update` operation only when its relevant fingerprint
differs from the desired digest. All other settings remain untouched.

Canonical JSON is byte-replayable. Independent review binds the exact bytes,
and a later complete authoritative census recomputes relevant fingerprints. Any
relevant difference makes the plan stale. The retained production observation
uses snapshot-preservation targets, so it proves planning and review with zero
operations; adversarial tests cover changed targets and every refusal mode.
